# Low Level Design (LLD) Learning Repository

## 📌 Overview
This repository is focused on learning and practicing **Object-Oriented Programming (OOP)** and **Low-Level Design (LLD)** concepts used in real-world software development and technical interviews.

The aim is to gradually build a strong foundation in:
- OOP principles
- SOLID design principles
- Design patterns
- Scalable & maintainable class design
- Hands-on LLD system implementations

> This is the initial version of the repo — currently starting with core OOP learning materials.

---

## 📚 Current Content
| File/Folder | Description |
|------------|-------------|
| `oops/` *(or your file name)* | Notes and examples of basic OOP concepts (Encapsulation, Inheritance, Abstraction, Polymorphism) |
